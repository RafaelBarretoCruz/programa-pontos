# Definição de pronto

Antes de encerrar qualquer etapa:

1. Execute os testes existentes.
2. Execute a validação definida para a etapa atual em docs/plan.md.
3. Confirme que nenhum teste anterior regrediu.
4. Confirme que a implementação respeita os ADRs.

Se qualquer validação aplicável falhar, corrija antes de avançar.
